https://github.com/mist64/msbasic, vendored unmodified

Only the files a pure-Microsoft configuration assembles are kept.
Deliberately NOT vendored:

  orig/*.bin        the original OEM ROM images (Commodore, Apple,
                    AIM-65, ...). Those are the machine vendors'
                    copyrighted binaries, not Microsoft's MIT release,
                    and regress.sh only exists to diff against them.
  defines_*.s       the per-OEM configurations
  cbm1_patches.s, {aim65,apple,kbd,kim,microtan,osi,sym1,w65c816sxb}_*.s
                    the OEM-specific ISCNTC/LOAD/SAVE/EXTRA reconstructions

  (cbm_iscntc.s is kept: it is an empty file -- a comment saying ISCNTC
   is a KERNAL function on the CBMs -- and iscntc.s includes it for
   every configuration that is not CONFIG_CBM_ALL, ours included.)

This is the split the licence research called for (docs/BUILD-LOG.md,
2026-08-24): Microsoft's 2025 source release is MIT, and a pure-MS build
sits squarely on it; a byte-exact OEM ROM rebuild would not. The K4510
configuration lives outside this directory, in ../k4510msbasic.asm, so
everything here stays byte-identical to upstream.

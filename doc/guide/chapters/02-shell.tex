\chapter{The Shell}\label{cha:shell}

The shell is what the machine boots into. It is a file manager, a program
launcher and a front door to the monitor, and every command here also works
from BASIC with a \verb|*| in front. Type \verb|HELP| for the whole command
set on one screen --- the text it prints is itself a file on disk, a hidden
one called \verb|/.HELP|.

\section{Files and directories}
Files live on the host: the \texttt{fs/} directory beside the emulator on
the desktop, the \texttt{k4510/fs/} folder of the SD card on the Pi. The
machine sees that directory as \texttt{/} and nothing above it. Inside,
one directory per language, and a few that are the machine's own:

\begin{center}
\small
\begin{tabular}{@{}l >{\raggedright\arraybackslash}p{0.70\linewidth}@{}}
\toprule
\texttt{/PRG} & machine-code programs: the demos, \texttt{EDIT} and \texttt{VI}, \texttt{TELNET}, \texttt{BUG} \\
\texttt{/EHBASIC} & EhBASIC programs \\
\texttt{/BBCBASIC} & BBC BASIC programs, for the Tube \\
\texttt{/FORTH} & Forth \\
\texttt{/CPM} & the Z80's drives, \texttt{A} to \texttt{P}, one folder each (Chapter~\ref{cha:cpm}) \\
\texttt{/SID} & music for \texttt{SIDPLAY} --- a link to your own HVSC copy, not shipped \\
\texttt{/SYSTEM} & the machine's own: \texttt{STARTUP.SAMPLE}, \texttt{BUGREPORTS/}, a \texttt{chargen.bin} if you add one \\
\texttt{/STARTUP.BAT} & yours; run at power-on (Section~\ref{sec:badstartup}) \\
\bottomrule
\end{tabular}
\end{center}

A bare name not found where you are is looked for in \texttt{/PRG},
\texttt{/EHBASIC}, \texttt{/BBCBASIC} and \texttt{/FORTH} as well, so
you rarely need a path; a name is matched regardless of case when the
exact one is absent; and \texttt{..} never climbs above \texttt{/}.

\begin{type}
DIR [A] [dir | pattern]     LS is the same
CD dir       CD ..          CHDIR is the same
MKDIR dir    RMDIR dir
RM name                     DEL and ERASE are the same
RENAME old new              REN and MV are the same
CP from to                  a file (COPY is memory: see Housekeeping)
TYPE name                   a screenful at a time; q stops
XD name                     a hex dump (HEX is the same); Esc stops it
LOAD name [addr]            SAVE name from.to
EDIT name    VI name        the editors, Chapter 8
\end{type}

Names that begin with a dot are hidden; \verb|DIR A| shows them.
\verb|DIR| also takes a directory to look in, or a pattern to match:
\verb|DIR PRG| lists that folder without going there, \verb|DIR *.PAS| and
\verb|DIR ?.TXT| match here (\verb|*| any run of characters, \verb|?| any
one), and \verb|DIR A *.BAS| means both at once.

\screen{shots/dir.png}{\texttt{DIR}: directories first in white, then files
with their sizes, two columns.}

\section{Running things}
\verb|RUN balls.prg| runs a program; so does \verb|RUN balls|, and so does
plain \verb|BALLS| --- an unknown word is tried as a program on disk before
the shell gives up, \emph{with its arguments}, the way REXX did it on the
mainframes. A program reads its arguments through the \texttt{ARGS} system
call; \verb|SAY| is the demonstration:

\begin{type}
SAY HELLO FROM THE DISK
\end{type}

prints \texttt{HELLO FROM THE DISK} --- there is no \texttt{SAY} command,
only a \texttt{say.prg} in \texttt{/PRG}. Try \verb|SIDPLAY|, the SID
jukebox; \verb|EDIT| and \verb|VI| are the editors
(Chapter~\ref{cha:editors}); and four words open whole languages:
\verb|EHBASIC| (Chapter~\ref{cha:basic}), \verb|BBC|
(Chapter~\ref{cha:tube}), \verb|FORTH| (Chapter~\ref{cha:forth}) and
\verb|CPM| (Chapter~\ref{cha:cpm}).

\section{SWAP: running one thing from inside another}
A program is loaded where the last one was, so starting one from inside a
BASIC would ordinarily flatten the program you were writing.
\verb|SWAP command| puts the caller away first --- the whole of the CPU's
memory, and the screen --- runs the command on a clean machine, and gives
the caller back untouched:

\begin{type}
*SWAP EDIT MYPROG.BAS
\end{type}

from EhBASIC edits a file and returns to your program, variables and screen
as they were. One level deep; the thing being run must be an ordinary
program, and a BASIC's far memory is not disturbed because nothing else
touches it. BBC BASIC needs none of this: it lives on the co-processor,
out of reach of anything running here.

\section{Aliases}
\verb|ALIAS| gives a name to a line.

\begin{type}
ALIAS                    list them
ALIAS LL DIR A           define one
ALIAS LL                 nothing after the name: remove it
\end{type}

Whatever you type after the alias is added to the end, so a definition
takes arguments. Aliases are tried \emph{last}, after every other rule, so
one can never hide a real command: \verb|ALIAS DIR ECHO no| is accepted
and \verb|DIR| still lists the directory. They live in memory --- in a
sideways bank, not in the 64\,KB --- so they survive a reset but not a
power cycle, which is what \verb|/STARTUP.BAT| is for.

\section{The network}
A URL is a file name. Anything the shell reads --- \verb|TYPE|, \verb|LOAD|,
\verb|CP|, \verb|RUN|, and the bare-word rule above --- accepts
\texttt{http://} or \texttt{https://} in place of a name, and the machine
fetches it:

\begin{type}
TYPE https://raw.githubusercontent.com/mlongval/bmc-k4510/master/README.md
CP http://example.org/game.prg game.prg
RUN http://example.org/game.prg
\end{type}

EhBASIC's \verb|LOAD| and BBC BASIC's \verb|LOAD| on the Tube take URLs the
same way. The idea is the C64's Meatloaf cartridge, where a disk name could
be an address on the internet; here it costs the ROM nothing, because the
ROM never looks at a name --- the host does the fetching. A typed line is 95
characters, and so is the longest URL.

A \texttt{tnfs://} URL is more than a file: it is a place. TNFS is the
little UDP file protocol the FujiNet and Meatloaf servers speak, and the
machine's current directory can be on one of them:

\begin{type}
CD tnfs://fujinet.online/
DIR
CD CBM
DIR
CD -
\end{type}

\verb|DIR| lists the server, a bare name loads from it (so \verb|RUN|, and
the bare-word rule, run programs straight off the internet), \verb|CD ..|
climbs, \verb|CD -| comes home. The prompt shows where you are. The server
is read-only from here.

For programs that want a live connection there is the \emph{N: device}
at \texttt{\$D900} (FujiNet's name for it): four channels, each a URL
opened for reading and writing --- \texttt{tcp://host:port} for a
connection, \texttt{http://} for a page. \verb|TELNET host port| is the
demonstration, a \texttt{telnet.prg} in \texttt{/PRG}: what you type goes
out, what arrives is drawn by JIM, the terminal (Chapter~\ref{cha:tube}),
so a BBS gets its ANSI colours and CP437 art and the cursor and function
keys go out as VT sequences; F12 hangs up (Escape belongs to the far end).
It turns the screen black while it is connected, because that is what
BBS art is drawn for, and puts your colours back when it hangs up.
The register map is in
Chapter~\ref{cha:io} and \texttt{core/net.h}. On the Pi the network is
the Ethernet port (DHCP); without a cable the device answers ``not
fitted'' and URLs are simply absent names. The Pi has no TLS, so
\texttt{https://} works on the desktop only, and its network wakes on
first use rather than at boot.

So that there is no guessing, this is the whole list of what the machine
speaks, and where:

\begin{center}
\small
\begin{tabular}{@{}l l l l@{}}
\toprule
\textbf{Scheme} & \textbf{What} & \textbf{Desktop} & \textbf{Pi} \\
\midrule
\texttt{http://} & fetch a file; a name anywhere a name goes & yes & yes \\
\texttt{https://} & the same, over TLS & yes & no \\
\texttt{tnfs://} & a directory on a TNFS server, read-only & yes & yes \\
\texttt{tcp://} & a raw connection, through the N: device only & yes & yes \\
\bottomrule
\end{tabular}
\end{center}

\noindent There is no FTP, on either machine, and no SSH. The Pi's
network is untested at the time of this printing.

\section{CAPSLOCK}
\verb|CAPSLOCK| toggles a caps-lock: while it is on, letters read from the
keyboard come up uppercase, so a language whose keywords are uppercase ---
BBC BASIC, EhBASIC --- needs no Shift held. Digits and symbols are
untouched, so it is a caps lock and not a shift lock, and Shift gives you
the \emph{other} case while it is on, the way a caps lock has always
worked. It is also suspended while a program is running, so a program
that wants lower case --- \verb|:q| in VI, say --- gets it, and the lock
comes back when the program does. \verb|CAPSLOCK ON|
and \verb|CAPSLOCK OFF| set it explicitly. It works from inside a BASIC
through the \texttt{*} escape: \verb|*CAPSLOCK| in BBC BASIC or EhBASIC.

\section{Scripts and the boot file}
\verb|EXEC name| runs a text file as shell commands, one per line. A line
whose first character is \verb|#| is a comment, and a blank line is
ignored. At power-on the machine runs \verb|/STARTUP.BAT| as such a
script, if it exists --- straight in, with no pause and nothing to
catch. It is the place to put your aliases;
\texttt{/SYSTEM/STARTUP.SAMPLE} is one to copy from. If one ever stops
the machine booting, page~\pageref{sec:badstartup} is the way out.

\section{The monitor}
\verb|MON| (old-timers may type \verb|WOZ|) opens the machine monitor at a
\verb|*| prompt; its grammar is Wozmon's, with 28-bit addresses:

\begin{type}
*E000.E00F           examine a range
*0300:A9 41 60       store bytes
*0300R               run from $0300
*X                   leave
\end{type}

\screen{shots/mon.png}{The monitor examining the ROM. \texttt{MON E000.E00F}
runs one line without entering the prompt.}

\section{Housekeeping}
\verb|INFO| is the machine's self-description; \verb|TIME| the clock;
\verb|MODE| and \verb|COLOR| set the text screen --- \verb|CLS| clears it and
\verb|CLG| clears the bitmap over it, whoever drew it --- both reach a
BASIC through the \texttt{*} escape, which is how you tidy up after a demo
that left its picture behind; \verb|FILL| and
\verb|COPY| work on memory; \verb|HUSH| silences all four SIDs at once;
\verb|LS| is \verb|DIR| for fingers that have used Unix too long.
\verb|LOGO| clears the screen and prints the startup banner again ---
the colour bars and the machine's own description --- which is a tidy way
to end a session or start a screenshot.
\verb|RESET| restarts the machine from the shell, the same cold start the
reset chord performs.

\verb|BENCH| measures the machine: how many frames a second this host
manages at the clock in force, then each clock of the menu's ladder for
two seconds with a note sounding on SID~0, reporting frames and gaps in the
sound for each, and the clock is put back. About 25 seconds; the report
goes to \pth{/SYSTEM/BENCH-NN.TXT}. A clock is right for this host when
it holds 60 frames a second with no gaps --- the machine's
\emph{optimal MHz} on that host. A recent desktop holds a hundred or
more; a Pi~3B+ holds fifteen; and that figure, not the setting, is the
one to quote when a program seems slow.

Several commands answer to more than one name, so that habits from
another machine mostly work: \verb|CD| is also \verb|CHDIR|, \verb|RM|
is \verb|DEL| and \verb|ERASE|, \verb|REN| is \verb|RENAME| and
\verb|MV|, \verb|DIR| is \verb|LS|, \verb|COLOR| is \verb|COLOUR|,
\verb|XD| is \verb|HEX|, \verb|BBCBASIC| is \verb|BBC|, and
\verb|CAPSLOCK| is \verb|CAPS|. \verb|CP| and \verb|COPY| are
\emph{not} the same command: \verb|CP| copies a file, \verb|COPY|
copies memory.

\verb|MODE| on its own says where you are; \verb|MODE n| moves. The second
number is the margin: 1 (the default) keeps a one-cell gap at the top and
the left, 0 uses every cell.

\begin{tabular}{llll}
\textbf{MODE} & \textbf{pixels} & \textbf{text} & \\
0 & 640$\times$480 & 80$\times$60 & the whole glass \\
1 & 640$\times$240 & 80$\times$30 & the machine starts here \\
2 & 320$\times$240 & 40$\times$30 & \\
\end{tabular}

The F7 menu, under Video, has the same two knobs: \emph{Resolution} shows
what the machine is actually in --- it follows a \verb|MODE| you type ---
and choosing another asks the ROM to perform it, because the console's
geometry belongs to the ROM and not to the host. \emph{Left/top margin}
is the second parameter.

The menu offers the same three, and what it saves is never smaller than
320$\times$240. VICKY can draw smaller fields than these, but they are for
a program that wants the pixels, not for a shell; a program asks for them
through the video registers (Chapter~\ref{cha:io}).

The picture is always painted into 640$\times$480: a 240-line mode has
each line drawn twice, and a 320-wide one has its pixels doubled
sideways. Raster lines and SHEILA's display list count the glass,
0--479, not the mode --- which matters the moment a program asks VICKY
for a 200-line field, where the first line of the picture is raster
line~40.

\section{When STARTUP.BAT is the problem}\label{sec:badstartup}
\texttt{/STARTUP.BAT} runs at power-on, and a bad one runs at every
power-on. There is no moment to catch --- the machine boots straight into
it --- so the way out is not a key held at the right instant but a switch
that stays where you put it: the F7 menu, under Shell:
\emph{Run STARTUP.BAT}. That setting is the host's, kept in
\texttt{k4510.cfg}, so it survives a power cycle and no wedged program in
the machine can take it away from you. Boot clean, fix the file, switch it
back on.

On the desktop there is a second way, for one boot only:

\begin{type}
./k4510 --no-startup.bat
\end{type}

\noindent (\verb|--no-startup| does the same, as does
\verb|K4510_NO_STARTUP=1| in the environment). It skips
\texttt{/STARTUP.BAT} for that run and touches nothing: the F7 setting
and \texttt{k4510.cfg} are left exactly as they were. That is the one to
reach for in a script, or when a startup file has wedged the machine and
you want a single clean boot to go and fix it.

\section{When something goes wrong}
Type \verb|DUMP ON|, make it go wrong again, then type \verb|BUG| and
answer its questions: the report it writes is the issue.
Appendix~\ref{cha:issues} is the whole of it, on two pages.

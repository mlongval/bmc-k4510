The Linux kernel's 8x8 console font, lib/fonts/font_8x8.c, GPL-2.0.

data/font8.bin is not vendored directly: data/mkfont.py reads the
kernel's font_8x8.c and writes 256 glyphs x 8 rows, MSB-first, with
glyph 0 blanked (the text layer's "nothing").  $20-$7E are ASCII and the
rest is code page 437.

What is known.  mkfont.py takes the kernel source file as an argument,
so which tree it was run against was never recorded and cannot be
recovered from the output -- that font has been unchanged in Linux for
decades, which is why nobody noticed.

To settle it, if it ever matters:
  python3 data/mkfont.py <linux>/lib/fonts/font_8x8.c /tmp/font8.bin
  cmp /tmp/font8.bin data/font8.bin
